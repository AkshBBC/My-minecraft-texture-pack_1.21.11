# Chat-GPT's Texture Pack

**OBSIDIAN // Performance 16x** — a lightweight Minecraft Java Edition 1.21.11 resource pack made by GPT for Aksh.

### Goals
- 16× textures for a small resource footprint
- darker, cleaner visual style
- higher-contrast ores and key items
- simple PvP-friendly silhouettes
- no shaders or gameplay changes

## Download

Get the latest packaged resource pack from:

`dist/Obsidian-Performance-16x-1.21.11.zip`

Extract/use that ZIP as your resource pack in Minecraft Java 1.21.11.

> This is the first prototype. More blocks, items, GUI, mobs, particles and environment textures can be added later.
